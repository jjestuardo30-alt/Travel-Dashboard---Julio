Travel Dashboard
Travel Dashboard es una aplicación web desarrollada con HTML, CSS y JavaScript que permite consultar información útil antes de viajar a diferentes destinos.

## Vista general

![Travel Dashboard - Selector](https://github.com/user-attachments/assets/3048c2ba-5577-4a66-b9fe-3b081c0bf2c6)

![Travel Dashboard - Londres](https://github.com/user-attachments/assets/353fbf5f-4a98-4ec7-9b34-2ffc0d673027)

La aplicación muestra datos en tiempo real sobre:

clima actual
probabilidad de lluvia
viento
estado del cielo
conversión de moneda
recomendación de viaje
Además, incluye:

cambio de idioma español / inglés
fondo dinámico en el header según la ciudad seleccionada
diseño responsive
Deploy en Vercel
El CV está publicado en el siguiente enlace:

Vista general
El usuario puede seleccionar una ciudad desde el menú desplegable y visualizar información actualizada del destino elegido.

Ciudades disponibles
Barcelona
London
Paris
New York
Tokyo
Funcionalidades
Selección de destino desde un menú desplegable
Resumen del destino:
ciudad
país
temperatura
moneda local
Información meteorológica en tiempo real
Conversión de moneda desde EUR a la moneda local
Recomendación de viaje dinámica según el clima
Cambio de idioma entre español e inglés
Fondo dinámico en la cabecera según la ciudad seleccionada
Interfaz responsive para distintos tamaños de pantalla
Tecnologías utilizadas
HTML5
CSS3
JavaScript (ES6+)
Open-Meteo API
Frankfurter API
APIs utilizadas
Open-Meteo
Se utiliza para obtener datos meteorológicos en tiempo real:

temperatura actual
probabilidad de lluvia
velocidad del viento
estado del cielo
Frankfurter
Se utiliza para convertir una cantidad en euros a la moneda local del destino.
